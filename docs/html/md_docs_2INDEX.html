3. Compiler / build pipeline

Stage Tool Script Output
venv bootstrap pip venv-build.sh venv/ (pygame, jinja2, cython, pystray, pillow, pandas)
cythonize cython --embed -3 build.sh aio_bin.c
compile gcc -O3 + python3-config build.sh aio_bin
wrap bash build.sh runs venv-build then cython + gcc
launcher symlink aiorewrite → aio_bin runnable binary
in-app build cython/cmake/ninja/meson/cargo aio.py build <system> per-target artifacts

The binary auto-resolves PYTHON_EXE to venv/bin/python3 and injects the venv site-packages, so the compiled artifact is self-sufficient.
